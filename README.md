# Austin Anderson portfolio

Live site: https://austinandersondesign.github.io/

- `index.html` is the whole site and the private editor. Open the editor at https://austinandersondesign.github.io/#edit
- `content.json` holds every word, setting and photo choice. The editor saves to it; you never need to edit it by hand.
- `photos/` holds the images. New photos uploaded in the editor are saved here automatically.
- Every save is a commit, so the History list in the editor (and this repository's commit history) can bring back any earlier version.

Do not rename this repository, the GitHub username, or `index.html`: printed QR codes point to the address above.
